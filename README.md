A program that draws one image summing up the world's news of Sunday 22 November 2026: a front page with a cartoon of President Zelenskyy as the top story — his "fair response" line on the Crimea Bridge strikes — and 40 verified stories from six regions, from the Baltic ship attack and the COP31 deadlock to Pant's record century in Wellington. Every story was first reported on 22 November 2026 and contradiction-checked. The program is pure Node.js standard library: its own PNG encoder and its own 5x7 bitmap font, no network, no dependencies, deterministic — two runs write byte-identical images.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
